API文档

状态：尚未开放。 检索功能与本开放 API 均未实现，当前不可调用。以下接口范式与返回字段是已确定的设计，不代表服务可用，也不承诺上线日期。

范式（对标 CBDB）：

GET /api/person?id=<九位数字>&o=json

参数：

参数必填说明
id是人物编号，九位数字（仅 0–9），例如 100000001。
o待定输出格式，目前仅支持 json；是否必填以正式开放时为准。

返回字段（与首页示例字段集一致，共 11 项）：

字段说明
person_id人物编号，九位数字，条目唯一键。
primary_name主姓名。
courtesy_name表字等别称；样例中为空字符串（填充规则以实现为准）。
birth出生信息对象，含 year、place；样例中缺失项为 null（以实现为准）。
death卒信息对象，含 year、place；样例中缺失项为 null（以实现为准）。
source_type源文献类型；样例值为 genealogy。
source_title源谱书名；样例为「费县季氏家谱」。
clan姓氏／宗族；样例为「季氏」。
branch支系；样例为「白露村支」。
migration迁徙地字符串数组；样例为 ["山东临沂费县"]。
notes转录的谱文附注（史料原文记载）。

错误码、限流、署名与鉴权：待定（尚未设计）。 本页不列出任何状态码、配额或调用限制，待设计完成后补入。

使用约定：

  • 对外只使用九位数字 person_id，系统不对外暴露任何内部编号。
  • 在世人物不入库，API 不提供在世人物记录。
  • 返回内容为史料转录，不等于客观史实；记录转录自家谱古籍，内容为史料原文记载。
  • 将来若开放批量或程序化取用，请注明数据集名称与取用日期（见《引用规范》）。

API Documentation

Status: not yet available. Neither search nor this open API has been implemented; the endpoint cannot be called today. The endpoint pattern and response fields below describe the design that has been settled — they do not mean the service is live, and no launch date is promised.

Pattern (following CBDB convention):

GET /api/person?id=<nine digits>&o=json

Parameters:

ParamRequiredDescription
idYesPerson ID: nine digits (0–9 only), e.g. 100000001.
oTBDOutput format; only json is supported at present; whether it is required will be settled at launch.

Response fields (the same 11 fields shown in the home page example):

FieldDescription
person_idPerson ID, nine digits; the unique key of an entry.
primary_namePrimary name.
courtesy_nameCourtesy name or other by-name; empty string in the sample (filling rules per implementation).
birthBirth object with year and place; missing items are null in the sample (per implementation).
deathDeath object with year and place; missing items are null in the sample (per implementation).
source_typeType of the source text; sample value genealogy.
source_titleTitle of the source genealogy; sample: 费县季氏家谱.
clanClan or surname; sample: 季氏.
branchBranch; sample: 白露村支.
migrationArray of migration places; sample: ["山东临沂费县"].
notesTranscribed note from the genealogy (as recorded in the source).

Error codes, rate limits, attribution and authentication: to be determined (not yet designed). No status codes, quotas or call limits are listed here; they will be added once designed.

Conventions:

  • Only the nine-digit person_id is exposed; no internal identifiers are ever published.
  • Living persons are not in the database, and the API serves no records of living persons.
  • Responses are transcriptions of historical sources and do not constitute verified historical fact: entries are transcribed from genealogical manuscripts and reflect what the source text records.
  • If bulk or programmatic access is offered in future, state the dataset name and the date of retrieval (see the Citation Guide).
