引用规范

CARD 的引用单位是单条人物记录，唯一键为 person_id——九位数字，例如 100000001。引用一条记录时，除 person_id 外，必须同时给出源谱书名（source_title）与支系（branch）：同名人物散见于多部家谱，缺了这两项，读者无法回溯原文。

中文引用模板（可照抄，替换尖括号内容）：

<作者/编者，若无则删去>：《谱名》（支系），<卷/页，若无则删去>，CARD（中华族裔人物资料库），条目编号 <person_id>，https://cardreader.top/，访问日期 <YYYY-MM-DD>。

示范（谱名、支系、编号取自本站首页示例）：

《费县季氏家谱》（白露村支），CARD（中华族裔人物资料库），条目编号 100000001，https://cardreader.top/，访问日期 <YYYY-MM-DD>。

引用时须注明其史料性质：CARD 所有记录转录自家谱古籍，内容为史料原文记载，不等于客观史实。行文应写作「家谱原文记载」，而非直接断言史实。CARD 条目是检索与转引的入口，不能替代原始谱书；正式引证仍须回到谱书原文核对。

批量取用或经 API 使用时，除上述各项外，还应注明数据集名称与取用日期；数据集版本号口径尚未确定，暂以取用日期标识所用数据。CARD 数据仅限非商业的公益与学术研究用途；商业使用须事先取得书面许可（联系：8236389@qq.com）。

Citation Guide

CARD's unit of citation is a single person record, keyed by person_id — a nine-digit number, e.g. 100000001. When citing a record, always supply person_id together with the source genealogy title (source_title) and the branch (branch). Namesakes occur across multiple genealogies; without those two fields a reader cannot trace the entry back to its source.

English citation template (copy as-is, replace the angle-bracket placeholders):

<Author/Editor>, <Title of the genealogy> (<Branch>), <vol./page, delete if not applicable>, CARD (Chinese Ancestral Repository of Descendants), entry <person_id>, https://cardreader.top/, accessed <YYYY-MM-DD>.

Chinese titles and branch names are kept in characters here; a romanization scheme is not yet decided.

Worked example (title, branch and ID taken from this site's home page):

<Author/Editor>, 《费县季氏家谱》（白露村支）, CARD (Chinese Ancestral Repository of Descendants), entry 100000001, https://cardreader.top/, accessed <YYYY-MM-DD>.

Citations should state the evidentiary status of the record: all CARD entries are transcribed from genealogical manuscripts; they reflect what the source text records, not absolute historical truth. Write "as recorded in the genealogy" rather than asserting a fact. A CARD entry is an index for retrieval and cross-reference, not a substitute for the original genealogy; formal citation should still be checked against the genealogy itself.

For bulk use or programmatic access, also name the dataset and the date of retrieval. Dataset versioning is not yet defined, so the retrieval date is what identifies the data used.
